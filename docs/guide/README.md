# Oxys user guide

Oxys helps you choose your best photos. You open a folder. You look at each photo with the keyboard. You give it stars, a color, or a reject mark. Then you send the best photos to your editor.

Oxys does not import photos. It does not make a catalog. It never changes your original files.

Press `?` in the app to see the keys for the current view. Every command is also in the menu bar. Use the Help menu search to find a command by name.

## What you need

- An Apple silicon Mac.
- macOS 27 or later.

## What Oxys does not do

- It does not edit photos.
- It does not sync photos.
- It does not delete photos. A reject is a mark. The file stays where it is.

Some planned features are not in the app yet. See [What is not available yet](troubleshooting.md#what-is-not-available-yet).
