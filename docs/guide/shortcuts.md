# Keyboard shortcuts

Press `?` in the app to see the keys for the current view.

- Bare keys use key position. They work with any input source.
- Bare keys do nothing while you type in a text field.
- `⇧` and a cull key: apply the choice and go to the next photo.

## Move

| Key | Does | Where |
| --- | --- | --- |
| `→` `←` | Next, previous photo | All |
| `↑` `↓` | Up, down a row | Grid |
| `Home` `End` | First, last photo | All |
| `G` or `Esc` | Show Grid | Loupe, Compare |
| `E`, `Return`, `Space` | Open in Loupe | Grid, Compare |
| `C` | Compare | Grid, Loupe |
| `-` `=` | Smaller, larger thumbnails | Grid |
| `⇥` | Hide or show toolbar and panels | Grid, Loupe |
| `⌥⌘T` | Hide or show toolbar and panels | All |

## Cull

| Key | Does |
| --- | --- |
| `1`–`5` | Set stars |
| `0` | Clear rating |
| `[` `]` | Rating down, up |
| `X` | Reject (press again to clear) |
| `6` `7` `8` `9` | Red, yellow, green, blue label (press again to clear) |
| `⇧` + any of the above | Apply and advance |
| `⌘Z` `⇧⌘Z` | Undo, redo |

## Zoom and RAW

| Key | Does | Where |
| --- | --- | --- |
| `Z` | Fit ⇄ 1:1, tap or hold | Loupe, Compare |
| Double-click | Fit ⇄ 1:1 at the pointer | Loupe, Compare |
| `⌘1` `⌘0` | 1:1, Fit | Loupe, Compare |
| `=` `-` | Zoom in, out | Loupe, Compare |
| `⌘+` `⌘-` | Zoom in, out | Loupe, Compare (in Grid, thumbnail size) |
| `⌥` + arrows | Pan a quarter view | Loupe, Compare |
| `⌥⇧` + arrows | Pan a full view | Loupe, Compare |
| `⌥Z` | Keep zoom between photos | Loupe |
| `⇧Z` | Link or unlink both panes | Compare |
| `R` | Show developed RAW | Loupe, Compare |
| `⇧R` | Always show RAW | Loupe |

## Analysis and info

| Key | Does | Where |
| --- | --- | --- |
| `F` | Focus peaking, tap or hold | Loupe, Compare |
| `⇧F` | Peaking mode: Edges or Fine detail | Loupe, Compare |
| `H` | Highlight clipping, tap or hold | Loupe, Compare |
| `S` | Shadow clipping, tap or hold | Loupe, Compare |
| `⌥H` | Clipping thresholds | Loupe, Compare |
| `I` | Cycle info: off, name and stars, EXIF, histogram | Loupe, Compare |
| `⇧I` | Histogram on or off | Loupe |
| `⌥⌘I` | Show or hide inspector | All |
| `⌃⌘I` | Move keyboard focus to inspector | All |
| `↑` `↓` | Previous, next EXIF value | Loupe |
| `⌘C` | Copy EXIF value | Loupe |

## Compare

| Key | Does |
| --- | --- |
| `⇥` | Switch active side |
| `←` `→` | Step the active side |
| `↓` | Swap select and candidate |
| `↑` | Next pair |
| `Z` | Both sides to 1:1 at the same point |
| `⇧Z` | Link or unlink zoom and pan |
| `⇧X` | Reject the active side and advance it |

## Select

| Key | Does |
| --- | --- |
| `⌘A` | Select all |
| `⇧⌘A` | Select none |
| `⇧⌘I` | Invert selection |
| `/` | Deselect the active photo |
| `⇧` + arrows | Extend selection (Grid) |
| `⌥⌘A` | Select by rating or label |

## Filter, sort and find

| Key | Does |
| --- | --- |
| `\` | Show or hide filter bar |
| `⌘L` | Filtering on or off |
| `⌘F` | Find by filename |
| `⌥⌘0` | Any rating |
| `⌥⌘1`–`⌥⌘5` | At least that many stars |
| `⌥⌘6`–`⌥⌘9` | Toggle red, yellow, green, blue |
| `⌥⌘X` | Cycle rejected: show, hide, only |
