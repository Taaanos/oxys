Oxys 1.0 is the first stable release. It adds the keys you can change, a film strip, focus mode, optional lens correction, a faster Grid, and a stronger security base. The bundle ID changed, so read "Before you update".

### Before you update

- The bundle ID is now `com.thanosam.Oxys` (it was `dev.oxys.Oxys`). Settings that you changed in 0.1.0 start from their defaults, and the thumbnail cache is made again. Your photos and XMP sidecars are not affected. You can delete the old folder `~/Library/Caches/dev.oxys.Oxys`.
- The full-screen key is now `⌃⌘F`, the system key. It was `⌘⇧F`.

### What is new

- **Your own keys.** In Settings > Keys, change, add, remove and reset the key of any command. Oxys shows a key that is already in use before it saves. Menus, the `?` list and the key hints change at once. Import and export your keys as a file. `F1` to `F12`, `Page Up`, `Page Down` and forward delete can be keys. A Photo Mechanic key set is included.
- **Film strip in Loupe.** A row of small thumbnails under the photo shows where you are in a burst, and which neighbors you already rated.
- **Focus mode.** `⇥` hides every panel except the RAW badge and the decision. In Compare, `⌥⇥` switches the side.
- **Optional lens correction for RAW.** Settings > RAW has a switch for the correction that the system decoder applies. It is off by default, so 1:1 still shows sensor pixels. It applies only to cameras that the decoder supports. The inspector shows if it is applied.
- **Grid.** The decision marks sit in one capsule on every cell, and the active cell has a glass lens.
- **Export.** An opt-in switch removes the location and the serial numbers from exported files.
- **Settings > Memory.** One button clears the thumbnail cache.
- **Install with Homebrew:** `brew install --cask taaanos/tap/oxys`.
- **License:** GPL-3.0-or-later. The name and the icon are not licensed for reuse.

### Faster, and safer on memory

- Grid: the slowest frame while scrolling went from 143–185 ms to 17–45 ms.
- RAW develop, 95th percentile: 470 ms at 24–33 MP, 276 ms at 48.8 MP, 480 ms at 61 MP.
- Extracting the embedded JPEGs takes 0.34 to 0.57 of the time of a plain copy.
- One memory budget covers preview frames, developed RAWs and loads in flight. Oxys frees memory when the system asks, and when it is idle.
- A held arrow key no longer starts a prefetch. Oxys limits how many files ImageIO opens at once, which fixes a crash in the system RAW decoder on large folders.
- Oxys refuses a picture that would need more than 250 megapixels to decode.

### Fixed

- A key pressed in the Settings window no longer rates or rejects the photo in the main window.
- The keypad digits show as "Keypad 1" and so on, so they differ from the digit row.
- A folder that disappears (an unplugged card) keeps the list and your decisions.
- After an unclean quit, Oxys starts empty and does not reopen the last folder.

### Security

- Every release now has a signature, `Oxys.zip.sig`, made with a key that is not on GitHub. See [Check the download](https://github.com/Taaanos/oxys/blob/main/docs/guide/install.md#check-the-download).
- The release build uses the hardened runtime.
- The file parsers limit nesting depth. Oxys refuses symlinked sidecars, checks the type and size of a sidecar before it reads it, and deletes only regular stale temp files.
- Developer hooks work only in a special build, never in the release.

### Known limits

- Cull and zoom can still miss one frame at 60 fps on large files. The capture time of 5,000 files takes about 3.7 s. Both are accepted for 1.0.
- The performance gate was not run again for this release.
- Only ART has been checked for sidecar compatibility. Lightroom Classic and RawTherapee are not tested. Lightroom Classic may ignore sidecars for JPEG, DNG and TIFF.
- VoiceOver and Full Keyboard Access have not been tested.
- Needs an Apple silicon Mac with macOS 27 or newer.
